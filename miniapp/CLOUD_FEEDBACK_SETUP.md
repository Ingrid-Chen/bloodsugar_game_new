# 玩家反馈功能部署清单

代码已经包含玩家提交页、反馈云函数和仅开发预览可见的管理页。首次使用前，需要在当前云环境完成下面三步。

## 1. 创建数据库集合

在微信开发者工具的“云开发 → 数据库”中创建：

- `feedback_items`
- `feedback_admins`

客户端不直接读写这两个集合，提交和管理都只经过云函数。数据库权限建议保持“仅管理员可读写”。

## 2. 部署两个云函数

在开发者工具中分别右键并上传部署：

- `cloudfunctions/submitFeedback`
- `cloudfunctions/manageFeedback`

选择“云端安装依赖”。如果更新了埋点，也重新部署 `cloudfunctions/trackEvent`。

## 3. 绑定管理员微信

1. 用开发版打开“测试数据看板 → 玩家反馈”。
2. 第一次会显示一串“管理员识别码”，点击复制。
3. 在 `feedback_admins` 集合新增一条记录：
   - `_id`：刚才复制的管理员识别码
   - `enabled`：`true`
   - `role`：`owner`
4. 重新进入反馈管理页。

`manageFeedback` 仍兼容 `ADMIN_USER_KEYS` 环境变量，但管理员名单集合更便于后续增加或停用管理员。没有配置管理员时，管理云函数不会返回任何玩家反馈；正式版用户也看不到管理入口。

## 数据边界

- 自动记录：反馈类型、反馈正文、来源页面、相关题目与选项、版本、匿名用户键、提交时间。
- 用户可选填写：邮箱、微信号或小红书号。
- 不采集昵称、头像、手机号、身份证、病历或真实血糖数据。
- 玩家提交页已经明确提醒不要填写病历和真实健康数据。
- 联系方式只用于回复对应反馈，不应另作他用。

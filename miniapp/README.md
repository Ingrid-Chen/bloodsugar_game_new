# 控糖生存指南 · 微信小程序

这是网页版游戏的微信小程序 MVP。技术上使用 Taro + React + TypeScript，保留现有 7 天游戏逻辑和视觉风格。

## 第一版包含什么

- 7 天生活选择主线
- 绿色 / 黄色双选项卡
- 血糖、心情、精力、饱腹四项模拟状态
- 每次选择后的数值反馈与科普提示
- 每日总结、失败页和最终战报
- 本地自动存档与继续挑战
- 匿名访问与游戏漏斗统计
- 健康科普和非医疗建议声明

第一版没有账号、支付或真实健康数据。昵称和游戏进度只保存在用户自己的微信本地存储中，不会随统计事件上传。详细统计使用微信云开发的匿名身份、云函数和数据库；云环境未配置时会自动关闭云端入库，不影响游戏运行。

云开发环境的创建、数据库和云函数部署步骤见 [`CLOUD_ANALYTICS_SETUP.md`](./CLOUD_ANALYTICS_SETUP.md)。

## 本地构建

在 `miniapp` 目录执行：

建议使用 Node.js 22；Taro 4.2.1 在 Node.js 24 下可能卡在配置转换阶段。

```bash
pnpm install
pnpm typecheck
pnpm build:weapp
```

编译成功后，会生成 `miniapp/dist/`。

## 用微信开发者工具打开

1. 安装并登录微信开发者工具。
2. 点击“导入项目”。
3. 项目目录选择本仓库中的 `miniapp` 文件夹，不要选择整个仓库。
4. AppID 会自动读取，无需重新填写。
5. 点击“编译”，确认首页、选择、科普提示、每日总结、失败和通关流程。
6. 点击“真机调试”或“预览”，在自己的微信里完整玩一遍。

如果只想查看已经生成的成品，也可以导入 `miniapp/dist`，但日常开发建议始终导入 `miniapp`。

## 上架前检查

- 在至少一台 iPhone 和一台 Android 手机上走完完整流程。
- 检查昵称为空、继续存档、重新开始、失败和通关路径。
- 对所有科普提示做一次最终内容校对，避免绝对化表达和个体化医疗建议。
- 确认平台后台的小程序名称、头像、类目、备案信息与本项目一致。
- 再从微信开发者工具上传体验版，邀请首批用户测试，不要直接发布正式版。

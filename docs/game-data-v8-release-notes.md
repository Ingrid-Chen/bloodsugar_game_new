# 题库与数值 v8 更新记录

- 数据版本：`2026-09-03-v8`
- 审核来源：`控糖生存指南_统一调整审核表_高难度版_2026-09-03.xlsx`
- 范围：58 个场景、116 个选项的标题、情境、选项文案、四项数值和“血糖小课堂”文案。
- 选项结构：每个场景有且只有一个更优项，前端随机交换左右位置，埋点始终使用稳定的 A/B 身份。
- 复盘结构：保存每局选择记录，根据非更优项的知识标签生成薄弱点，不使用通用的推测性文案。

## 死亡规则

- 低糖集中日只在第 2～7 天随机出现。
- 低血糖死亡必须在当天累积至少 2 个低糖风险选择；普通、合理的饮食选择不会单独导致低糖死亡。
- 第 1 天首次越界会触发一次新手保护；同日再次越界仍可能结束游戏。

## 可重现模拟

运行 `npm run simulate:balance`，会对 5 种选择策略各模拟 300,000 局。本版随机选择的正式校验结果：

- 总死亡率：70.0%
- 第 1 天死亡率：3.4%
- 低血糖占全部死亡：16.2%
- 低糖风险行为不足 2 次却低糖死亡：0 局
- 100% 选择更优项：0 局死亡

## 兼容与统计

- 旧版本进行中的存档不继续读取，避免旧数值与新规则混用。
- 匿名行为数据带上 `game_data_version`，看板只汇总当前版本。
- 新手引导标记升级为 v3，旧用户会再看到一次，并可从首页固定入口随时重看。

# 微信分享封面 1.0.3

- 生成方式：内置 ImageGen，参考 `miniapp/src/assets/images/s-start.jpg` 与 `miniapp/src/assets/app-icon.png`
- 正式素材：`miniapp/src/assets/share-cover.jpg`（500 × 400，5:4）

## 设计提示

将“小糖”人物插画与绿色、黄色分叉箭头头像结合，制作一张克制、有质感的微信小程序分享封面。人物位于左侧，头像作为右侧的选择机制核心符号；用两张无文字的食物选择卡、晨间至晚间的小时间轴和四条状态色暗示情境选择游戏。背景采用暖象牙白与淡黄色几何图形，不出现医疗器械、巨型食物、大段文字、夸张按钮或廉价儿童练习题风格。
